# 운영·연동 메뉴얼 (준비)

기능이 확정되기 전 **초안**입니다. 화면에는 브랜드 로고가 붙습니다.

| 대상 | 내용 | 노출 |
|------|------|------|
| 고객 | 가입·지갑 3방식·카드 발급·보안 (단일 본문) | HQ 회원앱, `/s/{slug}`, 파트너 3유형 모두 |
| API 파트너 | ICOCARD 키트, Partner API, 격리 | 파트너 포털 (delivery=api), 본사 전체 보기 |
| 서브 솔루션 | 브랜드 회원앱 `/s/{slug}`, 본사 키 | 파트너 포털 (sub_solution), 본사 |
| 서브 솔루션 단독형 | 업체 Wirex 키, 운영만, 재판매 키 없음 | 파트너 포털 (standalone), 본사 |

본사 관리자: **운영관리 → 메뉴얼** 에서 위 4종을 모두 봅니다.

접근권한 그룹(정산팀/발급팀/일반관리자), 메뉴 ACL, 사용자 히스토리·갱신은 `docs/ACCESS_CONTROL_ROADMAP.md` — **이후 개발**.
